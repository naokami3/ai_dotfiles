# ai-slop-review-ja

日本語文章からAI生成特有のパターン（AI臭・スロップ）を検出する Claude Code プラグイン。

技術記事、ブログ、note、Qiita投稿など、投稿前の日本語文章をレビューし、「誰が読んでもAIっぽいとわかる特徴」を構造化レポートとして指摘します。

## スキル一覧

| スキル | 説明 |
|--------|------|
| `ai-slop-review-ja` | 5レイヤー検出（語彙・文体・構造・コンテンツ・事実性）でAI臭を指摘し、修正方向を示す構造化レポートを出力 |

## 設計思想

このプラグインの責任範囲は「AIっぽく見えない自然な日本語」への修正方向を示すことだけで、特定の執筆者スタイル（一人称、常体/敬体、語彙の好み）への寄せは対象外です。スタイル寄せは別スキルまたは別ターンで行います。

### 事実性を最優先

Layer 4 で「具体性を出せ」と指示すると、書き直しエージェントが辻褄合わせで数値・期間・経験を**捏造するリスク**があります。本スキルは捏造リスクのある箇所を `⚠️ 事実性要確認` として明示し、書き直し前に執筆者に確認を求める設計になっています。

## インストール

```bash
# GitHub マーケットプレイスから
/plugin marketplace add naokami3/ai_dotfiles
/plugin install ai-slop-review-ja@ai-dotfiles

# ローカルテスト
claude --plugin-dir ./plugins/ai-slop-review-ja
```

## 使い方

```
/ai-slop-review-ja:ai-slop-review-ja
```

レビュー対象のテキスト（markdown可）を渡すと、以下の形式でレポートが返ります。

- 📊 サマリ（🔴重度 / 🟡中度 / 🟢軽度 / 📐構造的所見 / ⚠️事実性要確認の件数）
- ⚠️ 事実性要確認（捏造リスクのある具体記述）
- 🔴 / 🟡 / 🟢 各重度の指摘（行番号・引用・問題・修正方向）
- 📐 構造的所見（段落長・接続詞頻度・見出し構造）
- 🎯 書き直し優先順位
